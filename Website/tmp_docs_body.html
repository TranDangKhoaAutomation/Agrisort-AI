Tổng quan

AGRISORT-AI là hệ thống phân loại nông sản bằng AI, quản lý lô hàng và truy xuất QR theo mã lô.

Mục tiêu

  • Chuẩn hóa dữ liệu lô nông sản sau thu hoạch.
  • Tự động công khai truy xuất QR theo cấu hình quản trị.
  • Cung cấp bề mặt tích hợp đầy đủ cho đội phát triển web/app mở rộng hệ thống.

Chỉ số định lượng chính

  • Độ chính xác thử nghiệm: 93-96%.
  • Năng suất mục tiêu: 1.000-2.000 quả/giờ.
  • Thời gian quyết định mục tiêu: <= 200 ms.
  • Giảm lao động phân loại trực tiếp: 50-70%.

Phạm vi triển khai

  • Hợp tác xã nông nghiệp.
  • Cơ sở sơ chế sau thu hoạch.
  • Doanh nghiệp nông sản quy mô nhỏ-vừa cần truy xuất minh bạch.

Vai trò hệ thống

  • Visitor: xem landing, blog, truy xuất QR, gửi contact/tư vấn.
  • Partner: quản lý lô, import CSV, tạo lại QR.
  • Admin: duyệt đối tác, quản trị hệ thống, CMS, blog, API key.
